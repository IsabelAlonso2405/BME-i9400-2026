# Check-ins

One notebook per student, named `<your-github-username>.ipynb`.

## How your file gets here

1. Fork this repository to your own GitHub account
2. Clone **your fork** with GitHub Desktop
3. Run the meeting notebook in Colab, fill in your sections, and run all cells
4. `File ▸ Download ▸ Download .ipynb`, rename it to `<your-github-username>.ipynb`,
   and drop it in this folder inside your clone
5. Commit, push, and open a pull request

Full step-by-step instructions are in
[`notebooks/meeting01_course_launch_and_tools.ipynb`](../notebooks/meeting01_course_launch_and_tools.ipynb).

Do not edit anyone else's file.
