## How to use these notebooks

1. Click the **Open in Colab** badge.
2. `File ▸ Save a copy in Drive` — *before you type anything.* The course copy is read-only.
3. Run cells with `Shift + Enter`. If things get strange, `Runtime ▸ Restart session` and re-run
   from the top.

Colab is the required runtime and every graded activity assumes it. A local Python setup is
optional and unsupported. Nothing in this course requires a GPU.
